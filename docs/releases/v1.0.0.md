## Instalador com telas para Windows

O instalador para Windows agora é um programa com telas, sem terminal nem comando, e não precisa de nada instalado antes (nem .NET, nem Visual C++).

- Acha sozinho o .zip da dublagem baixado do [Nexus Mods](https://www.nexusmods.com/reddeadredemption/mods/855?tab=files) (não precisa extrair) e a pasta do jogo na Steam, na Epic e no Rockstar Games Launcher.
- Baixa sozinho o HDiffPatch oficial, do repositório do autor. Sem internet, usa o .zip oficial que estiver na pasta Downloads.
- Confere o arquivo do jogo antes e o resultado depois, pela impressão digital SHA-256, e guarda o original em `PTBR-backup`. Se algo falhar, o jogo fica com o áudio que tinha antes.
- Para voltar ao inglês, desinstale pela lista de aplicativos do Windows.

Passo a passo com as telas: [guia de instalação](https://github.com/scarletmodder/rdr1-ptbr-instalador/blob/main/docs/installation.md).

## Linux, Steam Deck e Windows sem o .exe

O zip de scripts continua, no mesmo formato da versão 0.7.1: extraia dentro da pasta do mod, ao lado do `LEIA-ME.txt`.

- Linux e Steam Deck: `bash instalar-linux.sh` (para remover, `bash instalar-linux.sh remover`).
- Windows: dois cliques em `Instalar dublagem.cmd` ou `Remover dublagem.cmd`. Os lançadores `.cmd` são novos: no Windows 11, "Executar com o PowerShell" fechava a janela sem fazer nada.

## Arquivos

- `Instalador-Dublagem-PTBR-RDR1-v1.0.0.exe`: o instalador para Windows.
- `Instalador-Dublagem-PTBR-RDR1-Scripts-v1.0.0.zip`: os scripts para Linux, Steam Deck e Windows sem o .exe.
- `SHA256SUMS.txt`: o hash de cada arquivo, para conferir o download.
